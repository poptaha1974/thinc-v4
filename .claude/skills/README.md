## قواعد عامة

- المهارة تصف طريقة عمل، ولا تُنشئ أرقاماً معيارية من عندها؛ كل عتبة رقمية مصدرها ملف حوكمة
  داخل `docs/` مع سوقها وتاريخ مراجعتها.
- الدليل الناقص يُسجَّل `NOT_COLLECTED` ولا يُحسب اجتيازاً ولا صفراً.
