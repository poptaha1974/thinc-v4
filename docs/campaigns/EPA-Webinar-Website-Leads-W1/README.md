## 2. تصميم الاختبار C01 مقابل C02

**القرار: Ad Set واحد + إعلانين (ABO)، مش Meta A/B Test.**

السبب رقم واحد: **الـ Learning Phase**. ميتا محتاجة **50 حدث `Lead` لكل Ad Set أسبوعياً**
عشان تخرج من التعلّم. لو قسّمنا الميزانية على خليتين منفصلتين، كل خلية تاخد نص الأحداث
وتفضل الاتنين في التعلّم طول الأسبوع — يعني قراءة ملوّثة **وأداء أضعف** في نفس الوقت.

| البنية | متى تكون هي الصح | التكلفة |
|---|---|---|
| **Ad Set واحد + إعلانين** ⬅️ المعتمد لـ W1 | الميزانية < 800 EGP/يوم | ميتا بتوزّع العرض لصالح الأقوى مبكراً → مقارنة منحازة جزئياً |
| Meta A/B Test (خليتين متطابقتين، جمهور حصري) | الميزانية ≥ 800 EGP/يوم | قراءة نظيفة إحصائياً، بس بتحرق ضعف الميزانية للخروج من التعلّم |

**عتبة التحوّل:** بميزانية 400 EGP/يوم لكل خلية و CPL متوقّع ≤ 40 EGP → 70 lead/أسبوع لكل خلية
(فوق عتبة الـ 50). يعني **من 800 EGP/يوم وطالع، انقل لـ A/B Test الرسمي في W2**.

**علاج الانحياز في بنية W1:** لا يُحكم على الخاسر قبل ما ياخد **2,500 ظهور** على الأقل
(قاعدة Kill رقم 2 في إطار Egy-Pioneers). لو ميتا خنقت أحد الإعلانين تحت 2,500 ظهور
بنهاية W1 → الاختبار **غير حاسم**، يتعاد في W2 بـ A/B Test رسمي، ولا يُشطب الإعلان.

## 5. مؤشرات W1 وقرارات البوابة

### 5.1 المؤشرات المستهدفة (تقديرية — تُعاير بعد W1)

| المؤشر | 🔴 أوقف | 🟡 راقب | 🟢 وسّع |
|---|---|---|---|
| Hook Rate (3s) | < 15% | 15–25% | > 25% |
| Hold Rate (ThruPlay) | < 25% | 25–40% | > 40% |
| CTR (Link) | < 0.7% | 0.7–1.5% | > 1.5% |
| CPM | > 150 EGP | 90–150 EGP | < 90 EGP |
| **CPL (تكلفة التسجيل)** | **> 60 EGP** | **30–60 EGP** | **< 30 EGP** |
| Landing → Lead CVR | < 15% | 15–25% | > 25% |
| Frequency (W1) | > 3.0 | 1.5–3.0 | < 1.5 |

> ⚠️ **مصدر الأرقام:** أرقام الـ Hook/Hold/CPM مأخوذة من مرجع Creative QA Gate v1.0 (سوق مصري).
> أرقام **CPL و CVR تقديرية لأول ويبينار ومفيهاش بيانات تاريخية** — تُعامل كـ Prior مبدئي،
> وتُستبدل بأرقام W1 الفعلية كـ Posterior قبل W2. مينفعش تُستخدم كمعيار محاسبة على W1.

### 5.2 شروط الإيقاف (Kill)

```
K1: إعلان صرف 1.5x من الـ CPL المستهدف (> 90 EGP) بدون تسجيل واحد  →  أوقفه
K2: CTR < 0.5% بعد 2,500 ظهور                                      →  أوقف الـ Creative
K3: CPM > 200 EGP لمدة 3 أيام                                       →  وسّع الجمهور أو أوقف
K4: Frequency > 3.5 خلال الأسبوع                                    →  Refresh
K5: صفر تسجيلات بعد 1,500 نقرة على الرابط                          →  المشكلة في اللاندنج مش الإعلان — أوقف وأصلح
```

### 5.3 قرار نهاية W1

```
C01 و C02 كلاهما ≥ 2,500 ظهور  →  الاختبار حاسم → كمّل بالفائز + اعمل Variant جديد منه لـ W2
واحد بس اللي اتعرض فعلياً        →  الاختبار غير حاسم → أعِد الاختبار في W2 بـ A/B Test رسمي
الاتنين تحت الـ 🔴              →  المشكلة في العرض نفسه مش الـ Creative → راجع الويبينار واللاندنج
```
