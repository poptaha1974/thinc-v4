## 7. القياس وقواعد القرار

**المسار الكامل — يُعرض حسب Ad ID و Angle:**

```
Impression → Click → LPV → Start Form → Lead → Confirmed → Attended → Deposit → Paid
```

**المؤشرات:** LPV/Click · Form Completion · Confirmed/Lead · Attendance/Confirmed ·
Deposit/Attended · Paid/Deposit · CPL · Cost per Attendee · Cost per Deposit · CAC ·
Revenue و Contribution Margin.

**قواعد حاكمة:**

- **لا إيقاف أو توسيع بسبب CTR وحده.** CTR يقيس قوة الهوك ولا يثبت نية شراء.
- **لا تُخترع Benchmarks.** حدود القرار الرقمية لا تُحدَّد إلا بعد اعتماد: ميزانية الاختبار،
  سعر البرنامج، قيمة الديبوزت وشروطه، هامش الربح، ومعدل التحول الحالي.
- **الفوز النهائي** لمن يحقق Lead مؤهلاً وحجزاً ودفعاً بكفاءة أعلى — لا لمن يحقق نقرات أكثر.
- **النجاح ليس الـLead**، بل الديبوزت بعد حضور الجزء المجاني (قاعدة CFO).

**أول ساعتين بعد النشر:** سلامة الإنفاق والتسليم · فتح الصفحة من الإعلانات · وصول Events و Leads ·
عدم تكرار أو فقد البيانات. وبعدها لا تعديلات كبيرة إلا لعطل تقني أو إنفاق بلا تحويلات وفق حد متفق عليه.
