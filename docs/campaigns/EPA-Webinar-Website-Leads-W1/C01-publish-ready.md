يتأكّد منها الـ Media Buyer بالترتيب — أي بند فاشل = وقف النشر.

- [ ] الـ 5 مدخلات المعلّقة اتعبّت فعلياً (مفيش `{{...}}` باقي في الإعلان)
- [ ] الدومين اتوثّق في Business Manager

- [ ] Test Events: حدث `Lead` بيوصل من المتصفح والسيرفر بـ **event_id واحد** (Deduplicated)
- [ ] تسجيل تجريبي حقيقي وصل الـ CRM ومعاه `utm_content=c01`
- [ ] صفحة التسجيل تحمّل في أقل من ثانيتين على 4G موبايل

- [ ] الجمهور المستبعَد (المسجّلين سابقاً) مربوط بالـ Ad Set
- [ ] الميزانية 500 EGP/يوم على مستوى الـ Ad Set (ABO) — مش CBO
- [ ] الإطلاق مضبوط على بداية يوم كامل (00:00) — مش وسط اليوم
