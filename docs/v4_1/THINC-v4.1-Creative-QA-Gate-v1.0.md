## المرحلة 4 — Pre-Launch Creative QA

### أ. فحص الـ Hook (3 ثوانٍ الأولى)
> اعرض الفيديو بدون صوت على 5 أشخاص خارج السياق.  
> إذا أقل من 3 فهموا العرض → أعد تصوير الهوك.

- [ ] الوجه أو الحركة أو النص الأول يوقف التمرير فوراً
- [ ] العرض أو المشكلة واضح في أول 3 ثوانٍ بدون صوت
- [ ] لا يوجد إنترو أو لوجو أو مقدمة في البداية
- [ ] الثانية الأولى ليست black screen أو fade in

### ب. فحص الـ Hold (التناسق البصري)

- [ ] كل 3 ثوانٍ فيها معلومة أو عنصر جديد — لا تكرار
- [ ] لا يوجد انقطاع مفاجئ في الإيقاع بين الثانية 3 والثانية 15
- [ ] الـ CTA واحد بس وواضح في آخر 3–5 ثوانٍ
- [ ] المدة بين 15–45 ثانية (الأمثل للـ Reels المصري)

### ج. فحص الـ Technical Specs

| المعيار | المطلوب | ✅ / ❌ |
|---|---|---|
| نسبة الأبعاد | 9:16 للـ Reels / 1:1 للـ Feed | |
| الدقة | 1080×1920 للـ Reels | |
| حجم الملف | أقل من 4 GB | |
| النص على الشاشة | أقل من 20% من المساحة | |
| Safe Zone للنصوص | تجنب أسفل 35% وأعلى 14% | |
| مدة الفيديو | 15–60 ثانية | |

### د. فحص الـ Quality Ranking المتوقع

| السؤال | النتيجة المتوقعة | ✅ / ❌ |
|---|---|---|
| الإعلان يتطابق مع صفحة الهبوط؟ | Quality Ranking: Above Average | |
| يوجد Social Proof (أرقام / آراء / شهادات)؟ | Engagement Ranking: يرتفع | |
| الـ CTA واحد ومحدد؟ | Conversion Ranking: يرتفع | |
| الفيديو أصلي غير مُعاد تدوير؟ | Creative Similarity Score: آمن | |
| صفحة الهبوط تحمل في أقل من 2 ثانية؟ | Bounce Rate: ينخفض | |

### 🚦 قرار الـ Pre-Launch Gate

```
✅ كل النقاط مكتملة     →  اجتاز القفل — انتقل للمرحلة 5
❌ أي نقطة في الهوك     →  STOP — أعد تصوير الـ 3 ثوانٍ الأولى
❌ أي نقطة في الـ Specs →  STOP — صحّح تقنياً قبل الرفع
❌ أي نقطة في الـ Hold  →  STOP — أعد ترتيب المحتوى بين ث3–ث15
```

## المرحلة 7 — Post-Launch Health Check (أول 48 ساعة)

### 🚦 نظام الإشارات الضوئية — معايير ميتا المرجعية (مصر)

| المؤشر | 🔴 أوقف فوراً | 🟡 راقب ولا تزيد | 🟢 Scale |
|---|---|---|---|
| Hook Rate | < 15% | 15–25% | > 25% |
| Hold Rate (3s → ThruPlay) | < 25% | 25–40% | > 40% |
| CTR (Link Click) | < 0.5% | 0.5–1% | > 1% |
| CPM | > 120 EGP | 80–120 EGP | < 80 EGP |
| CPC | > 6 EGP | 3–6 EGP | < 3 EGP |
| Frequency | > 3 | 2–3 | < 2 |
| Quality Ranking | Below Average | Average | Above Average |

### 🔁 شجرة قرارات الـ 48 ساعة

```
Hook Rate < 15%
  └→ أوقف + أعد تصوير الـ 3 ثوانٍ الأولى

Hook Rate ✅ لكن Hold Rate < 25%
  └→ ابقِ الهوك + عدّل المحتوى في الثانية 4→15

Hook Rate ✅ + Hold Rate ✅ لكن CTR < 0.5%
  └→ المشكلة في العرض أو الـ CTA — عدّل النص والزاوية

Hook Rate ✅ + Hold Rate ✅ + CTR ✅ لكن CPM > 120
  └→ راجع الـ Audience Overlap أو قلل حجم الجمهور

كل المؤشرات 🟢
  └→ ارفع الميزانية بـ 20% كل 48 ساعة
```

## 📌 ملاحظات التطبيق

- الـ Pre-Launch QA Gate هو **Blocking** — لا يمكن الانتقال لمرحلة الإطلاق بدون اجتيازه كاملاً.
- الـ Post-Launch Health Check هو **Decision Gate** — يحدد Scale أو Pause أو Iterate.
- الـ Benchmarks مبنية على معايير ميتا الرسمية ومحسوبة للسوق المصري (EGP).
- يُحدَّث الـ Benchmark كل ربع سنة بناءً على بيانات الحملات الفعلية.
